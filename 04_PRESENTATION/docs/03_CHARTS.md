# Графики, таблицы и числовые доказательства

## Сначала вопрос

| Вопрос | Подходящая форма |
|---|---|
| Кто больше / меньше | Горизонтальные столбцы, прямые подписи |
| Как менялось во времени | Линия или столбцы по времени |
| Что изменилось между двумя моментами | Два числа, парные столбцы или простой dumbbell |
| Что выбрать по нескольким критериям | Небольшая таблица с выделенным решением |
| Какова структура целого | Полоса долей; круг только при простой структуре и ясных подписях |
| Как устроен процесс | Этапы или схема связей, а не псевдодиаграмма |

Типы не являются запретом на другие обоснованные решения. Не повторять дизайн графиков из отрицательных референсов. Строить заново из данных.

## Достоверность — обязательная проверка

- Есть источник, период, единицы, база сравнения. Расчёты проверены отдельно от оформления.
- Проценты различаются с процентными пунктами; среднее — с медианой; просмотры — с уникальным охватом.
- У столбцов количественная ось начинается с нуля. Разрыв шкалы не скрывается. Для линий диапазон может быть ограничен, но явно подписан и не преувеличивает изменение.
- Пропущенное значение не равно нулю. Не соединять линией отсутствие наблюдения без явного обоснования. Различать «не было в выдаче» и «нет данных».
- Для позиции в поиске объяснить, что №1 лучше; направление оси явно видно.
- Составные столбцы использовать только для складываемых частей одного целого. Не суммировать несовместимые метрики.
- При сравнении периодов учитывать их длительность. Если нужны продажи в день, вычислять по исходным данным, не по высоте картинки.
- Совпадение события и роста не доказывает причинность. Сохранять ограничения исследования.
- Не переносить числа из старых референсов в новую презентацию как актуальные данные.

## Визуальные правила

Один основной аналитический вопрос на слайд. Один крупный график предпочтительнее трёх маленьких. Если два графика нужны для одного вывода, проверить, что оба читаются без увеличения; иначе разделить.

Основной ряд/период выделять лаймом, сравнение — нейтральным цветом. Дополнительные цвета брать из брендовых токенов при реальной необходимости различить ряды. Цветовой смысл сохранять во всей презентации. Не полагаться только на цвет: использовать подписи, тип линий или расположение.

Подписывать данные рядом, когда это заменяет легенду. Убирать второстепенную сетку и повторяющиеся цифры. Не удалять важные экстремумы, периоды и единицы. Округление единообразное, точные значения доступны в таблице.

Не применять 3D-перспективу, металлические сектора, свечения, тени на столбцах, объёмные оси и декоративные маркеры. Metal 3D — метафора, а не точная визуализация чисел. Не выдавать декоративную круговую 3D-иконку за распределение данных.

Сохранять график редактируемым: нативный chart, SVG или векторные элементы с исходной таблицей. Растровый экспорт для просмотра допустим, но не заменяет данные и редактируемый исходник. Генератор изображений не использовать для аналитики.

## Нет исходных данных

Запросить таблицу или использовать только проверяемые числа, которые предоставлены явно. Не восстанавливать точный временной ряд по скриншоту на глаз. До получения данных допустим макет с обозначенными плейсхолдерами, но его нельзя выдавать как финальный отчёт.

## Переработка плохого примера

В 2166:3736 одновременно размещены видео, три маленьких разноцветных графика и три крупных результата. Разделить на «результат контента» и «динамику поиска», выбрать по одному доказательству, сохранить периоды и оговорки. Не ограничиваться перекрашиванием линий в зелёный.
