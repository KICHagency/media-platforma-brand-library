# Включённая зависимость

Полный документационный Brand Core v1 текущего проекта включён без изменения. Вложенный AGENTS.md относится к работе внутри этой зависимости; презентационными решениями управляет AGENTS.md в корне пакета. Реестр ассетов содержит ссылки, а не экспортированные изображения. При обновлении Brand Core синхронизировать зависимость и повторно проверить правила презентаций.
