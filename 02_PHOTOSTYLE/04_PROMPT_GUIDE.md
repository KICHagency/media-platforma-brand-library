# Как пользоваться JSON

`prompts/photo_style.json` — расширение исходного JSON со слайда 17. Оригинал сохранён отдельно в `sources/`. Это переносимая спецификация задания, а не схема параметров конкретного API.

## Что менять

`replace_this`: person, action, pose, emotion, gaze, devices, environment, background_details, composition и green_light. Указать один `composition.camera_mode`. Выбрать `usage_mode`: environment, hero_cutout или group_cutout.

## Что сохранять

visual_style, lighting, realism, retouch_and_color, negative_prompt и запрет Figma AI. При смене типа фона применять `usage_rules`: графитовый интерьер относится к environment, прозрачность — к двум cutout-режимам. Вырезанный портрет не должен получать графитовую подложку из общих правил lighting.

## Как собрать запрос

1. Описание героя и действия из replace_this.
2. Правила только выбранного camera_mode.
3. Свет, реализм, обработка.
4. Правила выбранного usage_mode и output.
5. Негативные ограничения.
6. Референс с указанием его роли.

Примеры в examples — готовые полные JSON-задания. Для новой задачи измените сюжет, но не стирайте постоянные требования. Поля output задают желаемый результат; проверьте реальный размер и alpha после генерации, инструмент может интерпретировать их приблизительно.

`examples/generation_log.json` содержит фактические текстовые промпты тестов. Это журнал, а не более приоритетный стандарт: при расхождении применяйте текущие правила этого пакета. В журнале возможны повторяющиеся типажи; будущие серии должны расширять разнообразие.
