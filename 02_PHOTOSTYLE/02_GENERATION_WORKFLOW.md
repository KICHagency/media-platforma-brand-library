# Порядок генерации

## 1. Подготовить задание

Указать назначение, режим использования, формат, героя и возраст, одежду, действие, устройство, эмоцию, камеру, положение героя, место под текст и направление зелёного света. Если данных мало, выбрать разумный вариант и явно назвать допущение. Уточнять то, что действительно меняет результат.

## 2. Выбрать референс и JSON

Использовать один близкий по свету и ракурсу референс; при необходимости добавить второй. Указать роль: наследуем освещение и обработку, а не личность. Взять пример из `examples/` и изменить `replace_this`. Для группового кадра подготовить по одному заданию на каждого человека.

## 3. Получить изображение

Передать постоянные правила, выбранный режим камеры, сюжет и негативные ограничения вместе. Если инструмент не принимает JSON, преобразовать его в текст без потери требований. Если отдельного negative-поля нет, включить ограничения в основной текст.

Для environment фон является частью фото. Для hero_cutout и group_cutout нужен PNG с настоящей прозрачностью; фирменный фон собирается позже. Один вызов — один самостоятельный портрет или сцена.

## 4. Проверить и исправить

Проверить файл на масштабе 100% и в размере макета. Проверить вырезку на тёмном и светлом/фирменном фоне. Исправлять один конкретный дефект за итерацию, сохраняя удачные свойства кадра. При системной ошибке анатомии или геометрии перегенерировать.

Вывод тестовой серии: промпт не гарантирует целые пальцы и правильный ноутбук. Один кадр потребовал расширения композиции, другой — замены неправдоподобного открытого ноутбука на закрытый. Закрытое устройство допустимо только если это сохраняет смысл задания; нельзя подменять им сцену работы за экраном без согласования.

## 5. Собрать макет и сдать

Загрузить готовый файл в Figma, использовать актуальный знак/паттерн отдельным слоем. Масштабировать пропорционально. Проверить обрез и читабельность текста. Сохранить финальный промпт, номер версии, размеры, прозрачность, ссылки на слой и композицию, результат QA. Для серии проверять каждый файл.
