# Media Platforma — фотостиль

Версия 1.0 · 11 ноября 2026. Документальная база для генерации и использования фирменных фотографий.

## Быстрый старт

1. Прочитайте `01_PHOTO_STYLE.md` и `02_GENERATION_WORKFLOW.md`.
2. Выберите один режим из `03_USAGE_AND_COMPOSITION.md`.
3. Возьмите подходящий JSON из `examples/`, замените героя, действие, устройство и композицию.
4. Приложите визуальный референс из Figma. Одной ссылки недостаточно, если система не умеет читать файл.
5. Сгенерируйте фото и пройдите `05_QA_CHECKLIST.md`.

Для ИИ точка входа — `AGENTS.md`. Для человека без дизайнерского опыта — `06_Q_AND_A.md`.

## Статус правил

Основа — фотогайд и JSON со слайдов 16–20, требования автора и тестовая серия из 30 изображений. Серия принята как база для документации; это не отменяет проверку каждого нового результата. Операционные рекомендации (именование, запас кадра, порядок проверок) добавлены для воспроизводимости и не являются новыми цветовыми токенами бренда. Точные HEX для освещения в исходном JSON не заданы.
