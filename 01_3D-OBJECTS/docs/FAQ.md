# Вопросы и ответы

## Достаточно ли дать ИИ ссылку на GitHub?

Если система умеет читать репозиторий и изображения, README и AGENTS.md зададут маршрут. Если нет — приложите архив, JSON и референсы. Ссылка сама по себе не добавляет системе генератор картинок и доступ к Figma.

## Что именно передать для генерации?

AGENTS.md, STYLE.md, GENERATION.md, QUALITY.md, оба JSON, исходный конус и 2–3 подходящих PNG. Назовите предмет и назначение. Для готового объекта достаточно взять файл из каталога.

## Зачем отдельный негативный промпт?

Он перечисляет типичные ошибки: фон, пластик, жидкий хром, раздутые фаски, слабый рефлекс. Отдельный файл упрощает обновления и проверку. Если генератор не поддерживает специальное поле, передайте запреты обычным текстом.

## Почему конус — эталон?

Владелец выбрал его как ориентир качества металла, света и фасок. Это эталон поверхности, а не требование рисовать конус вместо каждого объекта.

## На слайдах чёрный фон. Нужно генерировать на чёрном?

Нет. Чёрный принадлежит фрейму просмотра. Ассет — прозрачный PNG. Экспортируйте отдельный объект, а не весь фрейм.

## Есть альфа-канал, но виден серый прямоугольник. Всё нормально?

Нет. В файле могут остаться полупрозрачные фоновые пиксели. Проверьте на контрастных подложках и исправьте фон; не скрывайте проблему чёрным слайдом.

## Свечение должно выходить за контур?

Нет. Нужен широкий зелёный рефлекс на металле. Внешний неоновый ореол и облако света не соответствуют стилю.

## Можно сделать поверхность целиком лаймовой?

В рамках этой системы — нет. Основа серебристая. Зелёный работает как локальное отражение источника.

## Почему не указывать один угол камеры для всей библиотеки?

Разные формы раскрываются с разных сторон. Повторение одинакового три четверти делает серию однообразной. Материал и свет связывают серию; камера может меняться.

## Можно зеркально отразить PNG?

Для макета это технически возможно, но это меняет направление освещения и может нарушить конструкцию. Для нового полноценного ракурса с другими гранями и светом нужна новая генерация.

## Можно убрать фон экспортом из Figma?

Прозрачный фрейм не удаляет фон, запечённый внутри растровой картинки. Сначала исправьте сам PNG.

## Можно использовать Figma AI?

Только после отдельного явного разрешения владельца на расход его кредитов. По умолчанию генерируем в ChatGPT и загружаем готовые PNG.

## Можно добавлять надписи, логотип и цифры?

Не внутрь объектов этой библиотеки. Подписи и данные верстайте отдельно. Для брендированного предмета потребуется отдельное задание и явное исключение из текущего стандарта.

## Диаграмма из библиотеки может показывать доли продаж?

Нет. Это декоративная метафора. Реальные доли нужно строить точной диаграммой по данным.

## JSON гарантирует такой же результат?

Нет. Это описание стиля. Результат зависит от модели, её версии, референсов и конкретного задания. Каждую генерацию нужно проверять.

## Все 30 изображений уже утверждены владельцем?

Они созданы и размещены в Figma в ходе работы. Отдельное утверждение каждого объекта не зафиксировано; не следует его предполагать.

## Этот репозиторий задаёт весь стиль презентаций?

Нет. Здесь описана только графика Metal 3D. Сетки, типографика, логотипы и фотостиль должны подключаться отдельными модулями бренд-библиотеки.

## Можно обрезать объект краем слайда или карточки?

Да. Новый пример использования разрешает обрезку форматом. Масштабируйте и сдвигайте целый PNG внутри фрейма, сохраняя узнаваемость предмета. Не обрезайте исходный файл библиотеки.

## Можно немного закрыть текст объектом?

Да, если композиция это позволяет и весь текст остаётся легко читаемым. Перекрытие должно быть небольшим и локальным. Если буквы или слова приходится угадывать, измените положение объекта. Универсальный допустимый процент перекрытия не установлен.

## Не противоречит ли это запрету cropped object в негативном промпте?

Нет. Запрет относится к генерации исходного ассета: он должен быть целым и пригодным для разных макетов. Намеренная обрезка уже готового PNG при вёрстке разрешена. По той же причине запрет text внутри генерации не запрещает отдельный текстовый слой в макете.
