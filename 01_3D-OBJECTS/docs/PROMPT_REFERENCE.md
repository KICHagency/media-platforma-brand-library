# Как читать и изменять JSON

Файлы описывают художественное задание. Это не API-схема и не код запуска. Не отправляйте JSON как HTTP body без адаптации к выбранному инструменту.

| Поле основного JSON | Можно менять? | Как использовать |
|---|---|---|
| version, brand | При обновлении стандарта | Не менять для отдельного предмета |
| subject | Да | Предмет, детали, конструкция; без текста на поверхности |
| reference | Путь при переносе файлов | Сам PNG нужно приложить или сделать доступным инструменту |
| material | Сохранять | Основа, сатинирование, небольшие фаски |
| camera.preset | Да | Выбрать один ракурс |
| camera.yaw_deg / pitch_deg / roll_deg | Да | Художественные указания, не гарантированная калибровка камеры |
| camera.alternatives | Справочник | Не генерировать все ракурсы сразу |
| lighting.key | Сохранять характер | Мягкий белый свет раскрывает металл |
| lighting.accent_color | Сохранять | #8BF500 — источник лаймового рефлекса |
| lighting.direction | Да | Согласовать со стороной предмета, видимой камере |
| lighting.coverage_target | Сохранять ориентир | 20–35%, визуальная оценка |
| output | Сохранять прозрачность и формат | PNG RGBA, целый предмет, свободное поле |
| negative_prompt | Сохранять; дополнять по дефекту | Не отменять базовые запреты |
| provider_policy | Сохранять | Figma AI только с отдельного разрешения |

В этой документации yaw означает поворот влево/вправо, pitch — взгляд сверху/снизу, roll — наклон в плоскости изображения. Разные системы могут понимать знаки и углы иначе; словесное описание нужного вида обязательно.

В negative JSON поле negative_prompt — короткая версия для передачи модели; categories раскрывают её подробнее. При сборке задания учитывайте оба. Схема не устанавливает весов негативных терминов: синтаксис вроде `term:1.5` не используется.

Чтобы поменять предмет, достаточно начать с subject и camera, затем проверить lighting.direction. Не меняйте material ради разнообразия: разнообразие строится формой, изгибом, позой и камерой.

## Обрезка и текст при использовании

`output.framing` и запрет `cropped object` относятся к исходному изображению, а не к границам финального макета. `text` в негативном промпте запрещает сгенерированные надписи внутри PNG, а не отдельную типографику макета. Правила композиции задаются в `usage-rules.json`: цельный объект, обрезка форматом и небольшое перекрытие текста с сохранением читаемости. Этот файл — инструкция вёрстки, не настройка генератора изображений.
