# Media Platforma — Metal 3D

Библиотека 30 предметных 3D-иллюстраций и правила создания новых объектов: сатинированный серебристый металл, заметный лаймовый рефлекс, прозрачный фон.

Документация 1.1 · визуальная система 2.0 · 11 ноября 2026.

## Начать работу

**Нужна готовая иллюстрация:** откройте [каталог](CATALOG.md), выберите PNG из `assets/`. Сохраняйте пропорции и прозрачность.

**Нужен новый объект:** передайте ИИ [AGENTS.md](AGENTS.md), [правила стиля](docs/STYLE.md), [инструкцию генерации](docs/GENERATION.md), оба JSON и исходный конус из `references/`. Текст инструкции сам по себе не заменяет изображения-референсы.

Готовый запрос для начала:

> Прочитай README.md и AGENTS.md этого репозитория. Создай один объект «[название]» для «[назначение]» в стиле Metal 3D. Используй исходный конус и близкие примеры из assets как визуальные референсы. Примени metal3d-prompt.json и metal3d-negative.json. Верни прозрачный PNG и результат проверки по docs/QUALITY.md. Генерируй в ChatGPT. Figma AI-кредиты без моего отдельного разрешения не используй.

Если ИИ не может открыть файлы репозитория, передайте архив или необходимые файлы вложениями. Одна ссылка не гарантирует, что конкретная система умеет читать репозиторий, просматривать PNG или генерировать изображения.

`assets/` содержит 30 PNG; `references/original-cone.png` — исходный эталон материала. Тёмные фреймы в Figma служат подложкой просмотра, они не должны попадать в экспорт объекта. В макете разрешены цельный объект, обрезка краем формата и небольшое перекрытие текста при сохранении читаемости — см. [правила размещения](docs/USAGE.md). Исходный PNG при этом сохраняется целым.

## Границы

Это модуль Metal 3D, а не полный брендбук. Он не задаёт типографику презентаций, сетки, фотостиль, логотипы и правила всей палитры бренда. JSON — переносимый бриф для модели, не готовый запрос конкретного API. Библиотека не содержит автоматического генератора.
