# Media Platforma — ASCII-графика

Версия 1.0 · 12 ноября 2026

Документальная база для генерации и применения монохромной ASCII-графики Media Platforma. Предназначена для дизайнера, заказчика без дизайнерского опыта и ИИ-ассистента. Это третий вид графики бренда, отдельный от Metal 3D и фотостиля.

## Как загрузить в базу знаний

Если система принимает один текстовый файл, загрузите `MEDIA_PLATFORMA_ASCII_KNOWLEDGE_BASE.md`. Он объединяет инструкции, Q&A, проверки, ссылки и JSON-промпты. Если система принимает несколько файлов, загрузите тематические MD и папку `prompts/`. Не загружайте одновременно сборный файл и его составные MD: это дублирование знаний. ZIP сначала распакуйте, если загрузчик не читает архивы.

Текстовая база не заменяет визуальные референсы: перед генерацией передайте изображение-референс из Figma. Одна ссылка не гарантирует, что ваша система сможет открыть макет и увидеть изображения.

## Статус правил

Основа — исходный слайд ASCII, созданные в Figma JSON/негативные промпты и серия из 20 изображений, которую заказчик оценил как подходящее направление. Процесс приёмки, именование файлов и рекомендации по размещению в этой документации — рабочая систематизация, а не цитаты из исходного слайда. Новые ограничения бренда при согласовании вносятся в следующую версию.

Изображения в архив не включены: они находятся в Figma по ссылкам. Документы и JSON можно поместить в папку ASCII будущего GitHub-репозитория. Лицензию на публичное распространение этот пакет не устанавливает.
