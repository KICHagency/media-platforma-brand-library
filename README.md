## Запрос для ИИ

> Прочитай README.md и AGENTS.md этой библиотеки, затем Brand Core и профильный раздел моей задачи. Проверь доступ к нужным визуальным референсам. Выполни задачу по правилам Media Platforma, сохрани факты, проверь результат и укажи ограничения. Figma AI-кредиты не используй. Задача: [материал, цель, формат].

Для презентации обязательно прочитать 04_PRESENTATION/AGENTS.md, правила плотности, графиков, ассетов и самопроверки. Один главный вывод на слайд; при перегрузе разделить материал, а не уменьшать шрифт. Белые и почти чёрные фоны — основа, лаймовые — смысловые акценты без механического чередования.

## Что физически хранится здесь

Все 172 содержательных файла пользовательского архива сохранены. Служебные файлы macOS не включены. Готовые изображения: 30 Metal 3D PNG и исходный конус. Фото и ASCII представлены документацией и ссылками Figma; их экспорты в исходном архиве отсутствуют. Шрифты находятся в 00_BRANDCORE/FONTS.zip.

Вложенный 04_PRESENTATION/brand-core — сохранённая зависимость презентационного пакета. Канонический общий раздел — 00_BRANDCORE. При обновлениях синхронизировать копию; не считать её отдельной версией бренда. ALL_DOCUMENTATION и KNOWLEDGE_BASE — объединённые версии инструкций для загрузки одним файлом, не дополнительные правила.

## Обновления

При изменении правил обновлять профильный документ, соответствующий JSON, объединённую базу знаний и CHANGELOG. Новые ассеты добавлять вместе с происхождением и результатом проверки. Проверка структуры: `python3 scripts/validate_library.py`. Генерации и визуальные тесты выполняются отдельно; структурная проверка не подтверждает качество дизайна.
