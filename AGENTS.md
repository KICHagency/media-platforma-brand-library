# Media Platforma · Инструкции для ИИ

1. Прочитай корневой README, 00_BRANDCORE/AGENTS.md и правила нужного раздела. Не переносить правила Учи.ру или других брендов.
2. Приоритет: актуальное прямое указание владельца → 00_BRANDCORE для общих правил → профильный модуль для техники исполнения → отдельный референс. Копия brand-core в Presentation не является независимым источником.
3. Metal 3D — основная иллюстративная графика; фото — когда нужны люди; ASCII — только фон; DIY — акцентная заливка. Не добавлять декор в ущерб смыслу.
4. Сначала использовать готовые подходящие ассеты и изучать их визуально. Для новых генераций читать основной и негативный JSON-промпты. Figma AI и кредиты пользователя без отдельного разрешения не использовать.
5. Для презентаций обязательно читать 04_PRESENTATION/AGENTS.md и docs/01_CONTENT_AND_DENSITY.md, 02_LAYOUTS.md, 03_CHARTS.md, 04_ASSETS.md, 05_REVIEW.md. Планировать один вывод на слайд, карту фактов и цветовой ритм. Не уменьшать текст ради вместимости.
6. Не использовать ассеты из отрицательных примеров Presentation. Проверять происхождение и вложенные источники по rules/references.json.
7. Не генерировать точные графики, логотипы или текст изображениями. Аналитику строить по предоставленным данным; не выдумывать показатели и источники.
8. Приватность сохранять: не публиковать репозиторий, не менять доступ и не отправлять материалы другим лицам без задачи владельца.
9. Если недоступны Figma, исходные данные или файлы, назвать конкретный пробел. Не утверждать, что изучил недоступное. Продолжать независимую часть задачи.
10. Завершать работу проверкой по профильному чек-листу. Фактическую проверку данных, программную проверку файлов и визуальную проверку отличать друг от друга.
